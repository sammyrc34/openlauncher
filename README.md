
# Open Android #

An open-source, offline-first Android launcher built specifically for aftermarket car head units.

## New Features

Most features from the original project are retained. Current changes are:
 - Custom tile layouts (eg 4x3, 5x2, 6x4)
 - More configurable colours 
 - Customisable light theme colours, saved separate from dark theme
 - More colour options including transparency
 - More responsive speedometer
 - Increased maximum UI widget & font size
 - Removed soundboard tile

## Existing Features

 - Day & night color themes including auto day/night
 - Modular tile grid. Tiles can be moved, resized.
 - Shortcut bar for launching specific apps
 - Smart Music Player tile for media players, radio.
 - Speedometer tile
 - Altimeter tile
 - Trip meter tile
 - System usage tile (cpu/gpu/ram)
 - Weather tile
 - Compass tile
 - App catalogue screen for launching other apps
 - First-run onboarding

## Planned Features

 - Navigation tile (possibly PiP or incorporating OSM or similar)
 - Additional media capability (seek support)
 - Automation options, eg launching media player

---

## Hardware

Assuming PiP support is added, targets Android 9+ devices with API v24 or greater. Compatibility may vary by device and software ecosystem.
